Reflection:
In your own words, what is the difference between git add and git commit?

In my personal understanding, the git add selects and prepares files that have been modified by placing them in an area for staging. While git commit takes those staged files and permanently records them into the local repository as a new version in the project history. This helps in keeping track of changes and updates in the project being created.
